# 💼 Portfolio Website

This is a personal **Portfolio Website** built using the **MERN stack (MongoDB, Express, Node.js)** along with **HTML, CSS**, and **Bootstrap**. It showcases my projects, skills, and includes functionality to perform **CRUD operations** for easy management of content.

## 🚀 Features

- 🧑‍💻 About Me Section
- 🛠️ Projects Showcase
- 📫 Contact Form
- ✏️ Admin Panel for CRUD operations on:
  - Projects
  - Skills
  - Experience
- 📱 Responsive design using Bootstrap

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Templating Engine**: EJS
